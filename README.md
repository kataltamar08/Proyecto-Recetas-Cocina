# Proyecto Recetas de Cocina
Repositorio para la organización y gestión colaborativa de recetas.

## Reglas de contribución:
- Cada receta debe estar guardada en la carpeta `recetas/`.
- Utilizar un formato claro con ingredientes y modo de preparación.
- Las propuestas de nuevas categorías (como postres) deben probarse en ramas independientes.
