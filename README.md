# Proyecto Recetas de Cocina
Repositorio para la organización y gestión colaborativa de recetas

## Reglas de Construcción:
- Cada receta debe estar guardada en la carpeta `recetas/`
- Utilizar un formato claro para los ingredientes y modo de preparación
- Las propuestas de nuevas categorias (como postres) deben probarse en ramas independientes
